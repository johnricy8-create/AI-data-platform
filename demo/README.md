# AI 电商数据中台 · 交互 Demo

这是正式开发前的高保真静态原型，聚焦 4 个核心页面：

- 经营概览
- 商品分析
- 数据接入
- AI 运营助手

## 运行

```powershell
cd demo
npm start
```

打开 `http://localhost:4173`。

不需要安装依赖，`npm start` 会启动零依赖 Node 静态服务器。图表库 ECharts 已放在 `vendor/` 目录，离线可用。

## 说明

- 所有数据为演示数据，页面内已标注。
- AI 回答为本地模拟，不调用真实大模型；正式版会接入 OpenAI 兼容 API，并保留无 Key 演示模式。
- 销售分析、报告中心在侧边栏中标记为“正式版”，Demo 未实现。
- 交互包括：日期/渠道筛选、图表联动、商品详情抽屉、表格排序、文件上传模拟、AI 问答、运营计划弹窗、报告保存提示。
